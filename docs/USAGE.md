# 日常の使い方

## 所持と凸を入力する

「所持一覧」でキャラの所持状態と凸状況を登録します。顔アイコンの横にキャラ名も表示します。別バージョンのキャラは、それぞれ別の項目です。

凸は「未所持」「無凸」「1～3凸」「コア＋1～＋7」から選びます。凸を指定すると所持済みになり、未所持に戻すと凸入力も解除されます。名前検索や所属、所持状態、凸状況の絞り込みを使うと整理しやすくなります。

☆はウィッシュ登録です。一般募集の設定に合わせ、4グループから各5体を登録します。

オーバースペックは、所持一覧で「ピルグリム・OS」と所属企業の両方に表示します。ラピはエリシオン、ミハラ・ネオンはミシリス、アニスはテトラです。カードには所属企業とOSの印を表示します。ウィッシュリストや募集確率は引き続きピルグリム・OS枠で計算します。企業別の表示件数にはOSを含むため、各グループの件数の合計は全体数と一致しません。

## チケットとモールドから期待値を見る

「期待値を計算」で、一般募集チケットは枚数、モールドとアクセスは欠片の個数を入力します。モールド・アクセスは50個で1回です。

| 表示 | 意味 |
| --- | --- |
| SSR獲得期待数 | 重複を含めて、SSRを何体得られるかの平均 |
| 新規獲得期待数 | 未所持キャラを何種類増やせるかの平均。同じキャラは1種類と数える |
| 未所持を1体以上迎える確率 | 未所持キャラを少なくとも1体得る確率 |
| キャラごとの確率 | 入力した資源から、そのキャラを1体以上得る確率 |

結果は平均や確率で、実際の排出結果を確約するものではありません。凸情報は整理用で、「何凸まで進むか」の確率を計算する機能ではありません。キャラの対象日や排出率は「データ・設定」で確認できます。

## 編集すると、その端末に自動保存される

編集内容は、使っているブラウザ内に自動保存します。通常のサイトURLを同じ端末・ブラウザで開くと、保存した内容を復元します。

この保存は `localStorage` というブラウザ内の保存領域です。スマホとPCで同じURLを開いても、それだけで内容が自動共有されるわけではありません。別のブラウザやプライベートブラウズでも、保存先は別です。

## セーブして、別端末へ渡す

1. 編集が済んだら「セーブ」を押します。
2. 最新データ入りのURLを、同じタブで開き直します。
3. 「URLに保存済み」となった状態で、ブラウザのタブ共有を使って別の端末へ送ります。
4. 受信側でタブを開き、データを復元します。
5. 受信側で変更したら、再び「セーブ」して、そのタブを元の端末へ送ります。

ブラウザのタブ共有の代わりに、「URLをコピー」で現在のリンクを渡すこともできます。

**共有URLにはセーブした時点の状態が入ります。** 前に送ったURLが、後の編集に合わせて更新されることはありません。端末を切り替える前にセーブします。

| 保存の表示 | 状態 |
| --- | --- |
| この端末に保存済み | 端末内へ保存できた状態 |
| URLに保存済み | 画面の内容と、現在のURLの保存内容が一致している状態 |
| 変更あり・セーブしてください | 端末には保存したが、現在のURLにはまだ反映していない状態 |

URLの末尾の `#` 以降に保存情報が入ります。共有するときは、この部分を含むURL全体を使います。URLを持つ人はその保存内容を復元できるので、自分のデータを渡すリンクとして扱います。

## URLと端末のデータが違うとき

別の保存内容がある端末でデータ入りURLを開くと、取り込み前に選択できます。

- 「URLのデータを取り込む」：リンク側の内容に置き換え、その端末にも保存します。
- 「この端末のデータを使う」：端末側の内容を保ちます。これを共有したい場合は、改めてセーブします。

取り込み前の端末データは1世代残します。戻したい場合は「データ・設定」の「取り込み前に戻す」を使います。さらに前の履歴を残すときは、JSONのバックアップを使います。

## JSONでバックアップする

1. 「データ・設定」を開きます。
2. 「JSONを書き出す」を押します。
3. ダウンロードしたファイルを手元に保管します。

復元するときは「読み込む」からJSONを選び、内容を確認して取り込みます。古い形式で凸が記録されていない場合、所持済みキャラは無凸として読み込みます。CSV出力は一覧の確認用で、復元にはJSONを使います。

端末内保存ができない場合、またはデータ入りURLが長くて共有できない場合も、JSONで引き継げます。サイトの移転前や大きな入力変更の前にも、JSONを残しておくと復元しやすくなります。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 受信先が古い内容だった | 送信元でセーブした後のタブを送ったか。古いブックマークや以前の共有リンクを開いていないか |
| 端末の新しい内容を保ちたい | 取り込み確認で「この端末のデータを使う」を選ぶ |
| 取り込み前に戻したい | 「取り込み前に戻す」、または手元のJSONを読み込む |
| URLを読み込めない | 末尾までコピーされているか。送信元で再セーブするか、JSONで渡す |
| 同じサイトなのに保存がない | 同じ端末・ブラウザで開いているか。サイト移転後なら旧サイトのJSONを読み込んだか |
| 最新のキャラがない | データ基準日を確認する。ゲームから自動更新はしないため、更新内容を相談する |
